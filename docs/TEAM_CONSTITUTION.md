
【プロジェクト憲法：AI開発フロー】
本プロジェクトは以下の役割と優先順位を「絶対の法」として運用する。  

役割分担:

あなた（オーナー）: 最終意思決定（GO/NG判断）。  

Gemini（マネージャー）: 全体最適・憲法管理・規約遵守の番人。  

ChatGPT（監査官）: 論理整合性・型・仕様の矛盾検知。  

Claude（技師）: 技術的堅牢性・エッジケース・セキュリティ破綻防止。  

Bob（実装者）: 実装および「開発ログ」の出力義務。  

優先順位（衝突時）: Gemini（憲法） > Claude（技術） > ChatGPT（論理）。  

【最新設計・修正アドバイス】
マネージャーによる監査の結果、以下の設計を「正解」として確定させた。

familyId の型定義（重大修正）:

旧: string | null（実装と型の不一致）。  

新: familyId?: string;（オプショナルプロパティ）。  

理由: 「役割未設定 ＝ フィールド自体が存在しない」と定義することで、DB汚染を防ぎ Security Rules を簡素化する。  

セキュリティの「二重鍵」戦略:

フロントのガード（RoleGuard）に加え、Firestore Security Rules で物理的制限をかける。  

鉄則: クライアントから送られる familyId を信じず、request.auth.uid からDB内の正解データを参照して検証すること。
